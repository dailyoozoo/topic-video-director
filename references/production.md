# 制作决策与质量检查

## 先选能支撑目标的素材

| 已有条件 | 可行路线 | 进入批量前的检查 |
|---|---|---|
| 连续角色视频 | 跟踪、抠像、修补后复用表演 | 干净帧、遮挡、嘴部位置、动作是否符合台词 |
| 已验收透明动作库 | 选择动作并合成 | 角色身份、画布、锚点、动作开始/结束状态一致 |
| 分层角色与绑定 | 用现有驱动器制作动作 | 关节、眼睛、嘴形可控，短段落无穿帮 |
| 单张角色图 | 先分层绑定或生成短动作 | 不把整体位移缩放冒充自然手部/面部表演 |
| 只有主题 | 先研究和脚本，再准备素材 | 提前说明角色和生成工具尚未就绪 |

有动作库时优先复用，缺失动作可以改为同样表达信息的镜头，但核心设计变化应纳入分镜确认。需要新的生成服务时先检查实际可用工具与预算约束，不能承诺不存在的 API。

为了让执行模型稳定工作，一次性准备角色包：角色参考、待机/眨眼/点头/指向/展示物品/开心等动作、透明度或可分离背景、画布与人物尺寸、嘴部锚点、干净脸部和嘴形、已验收预览、适用限制。先做其中本条视频需要的动作，避免无目的地建大库。

## 画面层级

参照 V2 时可用：背景 → 连续角色 → 局部嘴部 → 标题/Logo → 字幕。层级随镜头语义调整，字幕不能遮眼睛和嘴，装饰不能比主题信息更抢眼。

标题、名称、角色动作和字幕错开入场，给观众阅读时间；不要同时让所有元素弹跳。V2 的近似节奏是角色先进入、标题随后、Logo 在约 0.62 秒进入、名称在约 1.22 秒展开；这些是原案例的示范，不能硬套到所有时长。

同一条视频固定角色造型、字体、文本层级与字幕基线，变化来自信息、动作、配色和构图需求。每镜只强调一个主要信息；长解释可以跨镜头延续，不强制每段都是 4 秒。

## 声音决定时间轴

已确认台词 → 干净配音 → 实测时长与句子时间 → 镜头与动作 → 字幕/口型 → 音乐 → 输出。

- 新台词配新声音，文字变化同步更新字幕、时长、镜头和口型控制。
- 口型分析使用人声，避免音乐驱动嘴巴；换声轨后重新提取控制曲线。
- 卡通开合可用语音能量；精细发音要求音素/嘴形对齐。不能混称。
- 只处理嘴部局部，保护鼻子、下巴和衣领；静止时闭嘴，跟踪和插值后检查位置。
- 调整播放速度时统一动作、声音、口型三条时间映射。超过合理语速就改脚本或延长镜头。
- 混音检查可懂度、词尾截断、接缝爆音与音乐遮盖。没有试听能力时将该项留待检查。

## 复用视频的细节

旧字幕压住角色时，先找无字的干净参考帧，跟踪对齐后修补；模糊衣领不能长期替代真实纹理。旧字压嘴时恢复完整嘴部，避免半张旧嘴和新嘴重叠。

头部、身体、道具可能需要不同跟踪，不能将整幅画面当成刚体。变换后始终记录原图、裁切图与输出画布坐标的关系。

透明帧插值宜使用预乘 Alpha，避免黑边；光流遇到遮挡、突变和手指细节时可能出错，先看短段，必要时保留原帧或改接镜方式。

## 两层验收

技术检查：目标尺寸/帧率/时长、音视频流、全片解码、必要文件和素材可追溯。优先项目验证器；附带 `scripts/inspect_video.py` 可用于独立成片，它不修改视频，不评估艺术质量。

实际检查：

- 手机显示大小下标题、数字和字幕可读，画面与台词表达一致。
- 连续动作自然，手指/道具/发丝无明显跳变，抠像边缘不闪，旧字不残留。
- 面部稳定，嘴部不漂移、不拖动整脸，说话与停顿节奏合理。
- 每段开头、结尾、动作最大处以及切镜前后都看过；均匀抽帧不能替代这些位置的动态检查。
- 试听完整成片，确认词句、发音、音量、混音和接缝；音轨存在不能代替试听。

动态样片的作用是早发现失败路线。失败时回到对应层修复：动作不足补动作；抠像问题修素材；台词超时改内容或时长；不要用更多粒子、滤镜、抖动掩盖问题。
